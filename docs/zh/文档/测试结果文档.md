# 测试结果文档 — AutoSimulationTrainingAgent

测试对象为**智能体**（`src/agent/`）、评测框架（`src/eval/`）与其配置护栏（`src/training/config.py`）。
仿真环境（`src/envs/`）作为支撑物做集成冒烟与确定性验证。

运行方式：

```bash
python -m pytest -m "not slow"   # 单元测试（秒级，无网络）
python -m pytest                 # 全量，含 MuJoCo 集成测试
```

## 1. 测试策略

| 层次 | 目标 | 手段 |
|---|---|---|
| 单元 | 组件逻辑正确、边界安全 | 直接调用，mock 外部依赖 |
| 集成 | 组件协作、真实物理 | 真实 MuJoCo step，脚本化 LLM |
| 端到端 | 完整 ReAct 闭环 | 脚本化 LLM + stub 训练，无网络 |

**关键取舍**：LLM 与 PPO 训练都是慢/贵的，因此端到端测试用**脚本化离线 LLM**（`ScriptedLLM`）
和 **stub 训练**替代，仍覆盖 Harness 的全部控制流（循环、工具分发、反思、记忆、预算、故障注入）。
真实 LLM 与真实训练由 `scripts/run_agent.py`、`scripts/run_eval.py` 的实跑验证。

## 2. 用例清单

### 2.1 配置校验 `tests/test_config.py`（9）
覆盖智能体「护栏」：默认合并、部分覆盖、越界裁剪并告警、未知键忽略、`batch_size>n_steps` 结构修复、
奖励权重裁剪、非法 `net_arch` 回退、非 dict 段抛错、整型叶子保持 int。

### 2.2 记忆 `tests/test_memory.py`（7）
短期记忆 best/渲染；长期记忆跨实例持久化、按诊断去重、按任务过滤、**损坏 JSON 不崩溃**。

### 2.3 LLM 解析回退 `tests/test_llm_parsing.py`（7）
`deepseek-flash` 不总发原生 tool_calls，覆盖从自由文本/代码围栏/嵌套括号中提取 JSON 对象，以及无 JSON 返回 None。

### 2.4 工具层 `tests/test_tools.py`（18）
未知工具/畸形参数→错误而非异常；`error` 观测可被智能体读取；预算耗尽拒绝再训练；
会话结束后拒绝训练；`run_training` 归一化并回传摘要（stub 训练）；
**固定奖励护栏**：任务固定奖励时智能体传入的 `env.reward` 被强制覆盖并回告警；未固定时原样采用；
**`timesteps` 为自由超参**：可长于/短于默认预算，不被钳制；
**可视化开关透传**：`ToolContext.visualize` 正确传给 `train()`（默认开，可关）。

### 2.5 目标判定 `tests/test_agent_goal.py`（8）
客观成功判据：命中所有出现的条件才成功；分别在不达标速误差/跌倒率/最低回报时失败；空摘要=失败；
**仅用 `mean_lin_vel_error_max` 可评分**（速度跟踪任务形态）；**return + fall_rate 组合判据**。

### 2.6 端到端 ReAct `tests/test_agent_loop.py`（9）
脚本化 LLM 驱动完整闭环：
- 跑一次 trial → finish，客观判定成功；
- 每次 trial 后反思并写入长期记忆；
- **模型自评成功但客观未达标 → 判失败**（自评与客观解耦）；
- **故障注入后仍恢复**（错误作为观测、不烧预算连续重试）；
- trial 预算封顶（**显式给出 `max_trials` 时**）；
- **`max_trials=None` 时不受 6 次上限约束**：连续 8 轮 trial 后仍由 `finish` 收尾；
- 任务命令速度与起始配置正确进入提示词；
- **达标后 observation 追加"目标已达"早停信号**；未达标时不追加。

### 2.7 后训练可视化 `tests/test_viz.py`（5，含 1 slow）
- 学习曲线：由 `metrics.csv` 生成非空 `curve.png`；
- **坏输入不崩溃**：文件缺失 / 内容为垃圾 → 返回 `None`（不抛异常）；
- `_write_video` 至少产出 mp4 或 gif（非空）；
- 端到端（slow）：随机策略跑 30 步离屏渲染出非空视频文件；
  跟随相机（固定方位/俯仰/距离 + EMA 平滑）为 `render_rollout` 默认；
  帧数不足期望时长时自动换种子重渲（时长自检）。

### 2.8 环境集成 `tests/test_env_smoke.py`（3，标记 slow）
- reset/step 形状与有限性（obs 42 维、act 12 维）；
- 同 seed、全新实例 → 轨迹逐位一致；
- kp=80 时零动作静立 100 步不跌倒、高度 >0.2（PD 稳定域）。

## 4. 测试驱动修复的问题

| 问题 | 现象 | 修复 |
|---|---|---|
| 故障注入时序错误 | 注入的失败仍占用 trial 计数，测试 `errors=0` | 改为**分发前**注入，失败不烧预算，智能体重试 |
| 环境重置非确定 | 同一 seed 复用同一 env 对象，第 5 步起发散 | `reset` 先 `mj_resetData` 清空求解器状态；确定性契约改为「同 seed、新实例逐位一致」 |
| 确定性测试自身缺陷 | 用 `action_space.sample()`（全局 RNG）测种子复现 | 改用固定动作序列 |

## 5. 未覆盖 / 已知局限

- **真实 LLM 的稳定性**不做断言式测试（外部服务、非确定），改为实跑观测（见评测报告）。
- **步态是否真的学出来**依赖训练预算：短预算（~2e4 步）下策略仍趋于退化解，需显著加大
  `timesteps`（见评测报告与开发过程记录）。在当前最终奖励下，2e6 步 + 8 并行环境已能训出
  真正走路（`mean_lin_vel_error≈0.12`、`fall_rate≈0.10`）；测试只覆盖「环境可跑、可控、可复现」。
- 未做性能/压力测试（单机 CPU 场景下非关键）。
