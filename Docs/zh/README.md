# Auto Simulation Training Agent (ASTA)

> 虚拟环境中自主训练机器人的智能体框架，底层基于 MuJoCo，支持各种机器人和环境配置。

## 这是什么

> 🚧 待填充：一段介绍——ASTA 是做什么的、解决什么问题（自动分析仿真训练结果并自主调参，
> 直到达成预设训练目标），以及它和普通训练脚本的区别。

## 核心特性

> 🚧 待填充：3~4 条要点
> - 自主调参闭环（训练 → 分析 → 调参 → 再训练）
> - 三层可扩展架构（Env / Agent / Task）
> - 多模态结果分析（奖励曲线图、日志、指标）
> - 零构建文档 / 可复现评测 …
