## 术语表

> 🚧 待填充：从需求文档 §3 摘录，并补充说明。

| 术语 | 含义 |
|---|---|
| Trial | 一次完整的 PPO 训练（一组超参 + 一个训练步数），产出一个可评估策略 |
| Goal | 任务成功判据（速度跟踪误差阈值 + 摔倒率阈值） |
| Session | 智能体针对一个任务的一次运行，含若干 trial |
| Fixed reward | 任务固定的奖励函数，智能体不得修改，保证跨 trial 回报可比 |
