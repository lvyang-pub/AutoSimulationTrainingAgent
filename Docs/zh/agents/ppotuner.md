# PPOTuner

## 概述

一个用于在虚拟环境中利用 PPO 算法进行强化学习微调的智能体。

## 智能体设计

### 主循环

主循环采用 ReAct（思考-行动-观测）循环：大模型首先进行思考，之后选择工具调用，并观测工具调用产生的结果，基于结果进行进一步思考。这样的循环在单次实验和单次实验之间可能执行多次。

### 反思机制

反思机制位于主循环外，仅用于分析。每次训练结束后单独调用一次大模型，结合训练反馈（如输出日志、训练结果等）进行一次总结性描述，该描述将作为观测传入主循环。

### 智能体工具

**`run_training`**：执行一次 PPO 训练

| 参数 | 类型 | 说明 |
|---|---|---|
| `config` | dict | 超参数配置 |
| `timesteps` | int | 训练步数（自由超参） |
| `seed` | int | 随机种子 |

| 返回字段 | 说明 |
|---|---|
| `run_id` | 本次训练的唯一标识 |
| `summary` | 训练摘要信息 |
| `warnings` | 训练过程警告 |

---

**`evaluate_policy`**：对已完成的训练进行策略评估

| 参数 | 类型 | 说明 |
|---|---|---|
| `run_id` | str | 目标训练的标识 |
| `n_episodes` | int | 评估回合数 |
| `policy_mode` | str | 评估模式 |

| 返回字段 | 说明 |
|---|---|
| `mean_return` | 平均累计奖励 |
| `fall_rate` | 跌倒率 |
| `mean_lin_vel_error` | 平均线速度误差 |

---

**`get_metrics`**：获取训练的学习曲线摘要

| 参数 | 类型 | 说明 |
|---|---|---|
| `run_id` | str | 目标训练的标识 |

| 返回字段 | 说明 |
|---|---|
| （曲线摘要） | 各阶段奖励、损失等统计数据 |

---

**`list_trials`**：列出所有已完成的训练记录

| 参数 | 说明 |
|---|---|
| — | 无需参数 |

| 返回字段 | 说明 |
|---|---|
| （trial 列表） | 所有历史 trial 的 run_id 与基本信息 |

---

**`finish`**：标记本轮调参结束

| 参数 | 类型 | 说明 |
|---|---|---|
| `success` | bool | 是否达成调参目标 |
| `reasoning` | str | 结束原因说明 |

| 返回字段 | 说明 |
|---|---|
| （终结标记） | 通知 Harness 终止主循环 |

### 双层记忆

- **短期记忆**：单次执行内的多次 ReAct 循环中产生的历史信息。
- **长期记忆**：每轮会话结束后进行的总结性描述，通过文件形式持久化存储；在后续工作中用于整合历史经验，避免重复尝试。
