Lab B: 智能体软件开发（研发人员角色）

任务目标：以研发人员角色，基于 Agentic Engineering开发一个具有实际应用价值的智能体软件。

基本要求: 
1.    智能体软件设计与开发
选择一个具有一定复杂度的实际问题，开发一个能够自主完成多步骤任务的智能体软件。

2.    智能体技术应用
根据应用场景选择合适的 Agent 技术，包括但不限于：Reasoning、RAG、Tool Use、Memory、Agent Loop、Harness、Planning、Reflection、ReAct、Multi-Agent。不要求全部使用，应根据任务需求进行技术选型，并说明选择理由。

3.完整软件工程过程
完成：需求分析 → 软件设计 → 编码实现 → 测试验证

4.提交需求文档、架构文档、源代码、测试结果及开发过程记录，并演示系统。 

进阶要求：智能体评测与优化
建立一套可重复的测试任务和评价指标，对智能体进行系统评测，并至少完成 1 轮“评测 → 分析 → 优化 → 再评测”。

指标示例：
任务成功率：能否完成目标任务
结果质量：准确率、性能等
工具使用效率：工具调用次数及成功率
执行效率：时间、Token 或资源消耗
鲁棒性：面对异常输入或工具失败时的表现
