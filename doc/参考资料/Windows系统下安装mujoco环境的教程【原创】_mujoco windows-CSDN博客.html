先前在linux中的一些关于mujoco学习记录的博客：Mujoco仿真【xml文件的学习 3】_mujoco打开xml文件-CSDN博客

下面开始windows系统下安装mujoco仿真环境的教程记录：
Mujoco官网：MuJoCo — Advanced Physics Simulation

我们以安装3.2.0版本为例子，在download中直接下载对应的windows系统版本：

下载并解压 安装包 ，进入到bin目录下，并复制文件夹路径：

D:\Program Files\Mujoco\mujoco-3.2.0-windows-x86_64\bin

有了 文件路径 后，继续进行环境变量的配置：

在系统变量中找到path并选中，随后点击编辑：

 在弹出的编辑界面中，点击新建后复制先前的bin文件夹路径，并保存确定：

一直“确定”退出即可，这时windows系统下的mujoco环境配置基本完成。

下面开始上手windows系统下的mujoco：

我们进入到mujoco文件夹中的bin目录中，找到simulate.exe执行文件：

点击simulate.exe执行文件，可以发现弹出mujoco仿真环境的显示界面：

下面我们回到上一级目录，进入 model 文件夹中的car文件夹中，将car.xml文件拖拽到刚刚弹出的mujoco仿真环境的显示界面：

可以发现xm文件的加载无误，mujoco仿真环境（windows系统）下的安装成功！
